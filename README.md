# BiblioMap 

Projeto Integrador do curso de Assistente de Logística (SENAI Caxias). 
Sistema para controlo de estoque, endereçamento físico e rastreabilidade do acervo bibliográfico e patrimonial.

###  Sobre o Projeto
O BiblioMap é uma solução web para modernizar a gestão do acervo e controlo patrimonial, permitindo a localização exata dos exemplares por rua, estante e prateleira, além do histórico completo de movimentações.
